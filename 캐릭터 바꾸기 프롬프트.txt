==============================================
 MomongaPet - 내 캐릭터로 바꾸기
==============================================

[사용법]
1. 아래 "GPT에 붙여넣을 내용"을 통째로 복사해서 ChatGPT에 붙여넣고,
   바꾸고 싶은 캐릭터 그림을 같이 첨부하세요.
2. GPT가 만들어 준 zip 파일을 받아서 압축을 푸세요.
3. 펫을 우클릭 → "스프라이트 폴더 열기"
4. 열린 폴더에 있던 기존 PNG를 전부 지우고, 받은 PNG를 넣으세요.
   (일부만 넣으면 없는 동작은 기본 모습(idle)으로 대체돼요)
5. 펫을 우클릭 → "스프라이트 다시 불러오기"

마음에 안 드는 동작이 있으면 GPT에게 "walk만 다시 만들어줘"처럼 부탁하고
그 파일만 바꿔 넣으면 돼요.


==============================================
 GPT에 붙여넣을 내용 (여기부터 끝까지 복사)
==============================================

첨부한 캐릭터로 데스크톱 펫용 스프라이트를 만들어줘.

[만들 동작] 이름(프레임 수): 설명
- idle(4): 가만히 서 있기. 숨 쉬듯 살짝 움직임
- walk(4): 걷기. 반복 재생되니 자연스럽게 이어지게
- drag(4): 마우스로 잡혀서 대롱대롱 매달린 모습
- jump(3): 뛰어오르기 (웅크림 → 위로 뻗음 → 공중)
- fall(1): 떨어지는 중. 팔다리를 벌림
- sleep(4): 엎드리거나 웅크려서 자기. "Z" 표시 있어도 됨
- dizzy(4): 떨어진 뒤 어질어질. 눈이 빙글빙글
- notice(4): 머리 위에 "!"가 뜬 놀란 모습. 순서 고정:
    1번 서서 왼쪽 보기 / 2번 서서 오른쪽 보기 / 3번 걷다가 왼쪽 보기 / 4번 걷다가 오른쪽 보기
- watchright(3): 오른쪽 아래를 내려다보기. 몸은 그대로, 눈동자만 조금씩 이동
- watchleft(3): watchright를 좌우 반전한 그림

[그림 규칙]
- 캐릭터는 기본적으로 오른쪽을 보게 (notice, watchleft만 예외)
- 모든 프레임에서 캐릭터 크기와 발 위치가 똑같아야 함
- 그림자, 바닥, 테두리, 글씨 없이 ("!"와 "Z"는 괜찮음)
- 한 동작마다 이미지 1장에, 프레임을 가로 한 줄로 간격을 두고 배치
- 배경은 단색 #00FF00 그린스크린

[파일로 만들어 줘]
그림을 다 만들면 Python으로 다음을 처리해서 zip 하나로 줘:
1. 초록 배경을 지워 투명하게 (가장자리 초록 번짐도 제거)
2. 프레임별로 잘라서, 256x256 투명 PNG로 저장
   - 캐릭터는 가로 가운데, 발은 이미지 아래쪽 끝에 맞춤
   - 모든 동작에서 같은 배율로 줄여서 캐릭터 크기가 일정하게
3. 파일 이름: 동작이름_번호.png (예: idle_01.png, idle_02.png, walk_01.png ...)
4. 전부 하나의 zip으로 묶기
